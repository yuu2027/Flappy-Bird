# Flappy Bird

Unity で作成した Flappy Bird 風の 2D サバイバルゲームです。障害物を避けながら、できるだけ長く生き残ることを目指します。

## 遊び方

1. タイトル画面でキャラクター選択ボタンを押し、使用するキャラクターを選びます（未選択のままではスタートできません）
2. スタートボタンでゲーム開始
3. **Space キー**でジャンプし、上下から迫る障害物を避けます
4. 障害物に当たるとゲームオーバー。生存時間がスコアになります
5. リザルト画面から「リトライ」または「タイトルへ」を選べます

## 主な機能

- **キャラクター選択**：タイトル画面で選んだキャラクターがゲーム中のプレイヤーとして使われます
- **障害物のランダム生成**：1 本 or 上下 2 本の障害物をランダムに出現させます。オブジェクトプールで管理しています
- **難易度上昇**：経過時間が 20 秒を超えると、単体の障害物が上下に揺れながら迫ってきます
- **ランキング**：生存時間の上位 3 件を JSON（`Assets/Data.Json`）に保存し、リザルト画面に表示します
- **演出**：背景の無限スクロール、ゲームオーバー時のカメラシェイク

## 動作環境

- Unity **6000.0.14f1**（Unity 6）
- Universal Render Pipeline（2D）
- TextMesh Pro

## セットアップ

1. このリポジトリをクローンします
2. Unity Hub から `Flappy-Bird` フォルダをプロジェクトとして開きます
3. `Assets/Resourcese/Scenes/Title.unity` を開いて再生します

## ディレクトリ構成

```
Assets/
├── Resourcese/
│   ├── Scenes/         # Title.unity（タイトル）, Main.unity（ゲーム本編）
│   ├── Scripts/
│   │   ├── TitleGame/  # タイトル画面・キャラクター選択
│   │   └── MainGame/   # プレイヤー操作、障害物、タイマー、ランキング等
│   ├── Arts/           # スプライト・プレハブ
│   └── Materials/      # 背景用マテリアル
├── Buttons/            # UI ボタン画像
└── Data.Json           # ランキングの保存データ
```
